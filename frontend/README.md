# Frontend

Next.js App Router with strict TypeScript, Tailwind CSS, TanStack Query, Zod, and React Hook Form. Organize route composition in `app/`, domain UI and data hooks in `features/`, reusable primitives in `components/ui/`, transport helpers in `lib/api/`, cross-feature hooks in `hooks/`, and shared contracts in `types/`.

Set `NEXT_PUBLIC_API_URL` in `.env.local`. Run `npm install`, then `npm run dev`. Use `npm run lint`, `npm run typecheck`, and `npm run build` before merging.
